宅地建物取引士（宅建）学習ガイド

12週間で、宅建の主要4分野を順に整える。

年度別の本試験演習と分野別ミニテストを往復しながら、根拠を言える知識と解答スピードを積み上げる学習アプリです。

平成28年度〜令和7年度 600問収録 12週ロードマップ

50問年度別模試を通しで確認

宅地建物取引士資格試験（宅建士）過去問ベースの演習ガイド
試験の概要

宅地建物取引士資格試験は、不動産取引に関する法律知識を問う国家資格試験です。不動産業界だけでなく、建設、金融、相続、資産運用、不動産管理などでも活用しやすい資格です。

試験形式四肢択一式50問。宅建業法、権利関係、法令上の制限、税・その他から出題されます。
収録年度平成28年度〜令和7年度
収録問題数600問（R2/R3の追加回を含む）
分野構成権利関係 / 法令上の制限 / 宅建業法 / 税・その他
模試形式各年度の 50問を通しで演習

合格点は年度で変動するため、過去の合格点だけを見てギリギリを狙うのは危険です。学習上は50問中36〜38点、できれば38点を安全目標にします。

得点戦略
区分目標・取り方
宅建業法20問中18点。合格のカギになる最優先の得点源。重要事項説明、37条書面、免許、広告、報酬を落とさない。
法令上の制限8問中6点。宅建業法と合わせて先に固め、都市計画法・建築基準法の数字、区域、例外を短い表で反復する。
税・その他8問中5点。5問免除範囲、税、価格評定は暗記で拾える問題を確実に取る。
権利関係14問中8点。民法は難化しやすく得点が安定しにくいため、深追いしすぎず頻出論点を優先する。
勉強時間の目安
  • 完全初学者は250〜350時間、不動産や法律に慣れている人は180〜250時間が目安です。
  • 選択肢を見て、どの論点を問われているか判断できる状態まで仕上げます。
合格に直結する勉強法
  • 学習順は、宅建業法 → 法令上の制限 → 税・その他 → 権利関係を基本にします。
  • 民法に時間を使いすぎず、まず宅建業法を20問中18点取れるレベルまで仕上げます。
  • 過去問は正解肢だけでなく、不正解肢がなぜ違うのかまで確認します。
よくある失敗
  • 権利関係に深入りしすぎて、得点源の宅建業法が固まらないこと。
  • 過去問を解くだけで終わり、選択肢ごとの根拠説明ができないこと。
